- (constraint) One A4 page. Body type is not shrunk to fit. Overflow drops in the edition.md order.
- (constraint) Render with WeasyPrint from the kit template, table grid, CSS, and fonts. A browser is not the renderer.
- (constraint) Paper language and dashboard language default to Hungarian and are separate settings. Headlines stay in the feed language.
- (constraint) USB printer through CUPS on a Pi 3B+. A Windows-only host-based driver is not a usable printer.
- (constraint) No build until NTP sync, because the Pi 3B+ has no battery-backed clock.
- (constraint) A news model returns IDs only. Code applies quotas and prints the original headline, publisher, and time.
- (constraint) Scheduler and dashboard are separate processes. A dead dashboard does not stop a scheduled print. A dead scheduler is visible on the dashboard and /status.
- (constraint) Remote access is the operator VPN routing the LAN subnet. No port is opened for a cloud monitor.
- (constraint) Hold defaults on for print and upload together. Auto-approve defaults off.
- (constraint) /status defaults to no login and returns no personal data. Secrets never reach the browser. The UI shows saved and replace only.
- (constraint) Cloud PDF defaults to trimmed and is rendered from the same snapshot as the print PDF.
- (constraint) Missing weather or almanac values are omitted. No guessed number is printed.
- (constraint) Weekend notes may be warmer and still follow the llm.md copy rules.
- (constraint) Local files kept 30 days by default, Dropbox indefinitely, both configurable. Dashboard history matches the local period. Name day starts on and can be switched off.
- (constraint) v1 alerts are dashboard banners and /status only. Checks and banners are in operations.md.

- (decision) Chomsky, Libre Franklin, and Newsreader are SIL Open Font License 1.1 faces, so the app may ship those font files. The rest of the kit is not shipped. .gitignore lists The-Firstname-Times-Setup-Kit-v17.3/.
- (decision) The printer is a Brother on USB, driven by CUPS. Many Brother printers work driverless or with printer-driver-brlaser. The exact model is recorded when it is plugged in at milestone 0, which still confirms detection and a test page.
- (decision) Calendar and tasks are both Baikal on one CalDAV server. Host, username, and password are settings. A fresh install has an empty host. The operator's personal URL is not written into the spec, the code, or the default config.
- (decision) Name days use the MIT static table froccsos/nevnapok-json, compiled from the MEK listing last updated July 1997. Print the day's main names. Works offline. Credit the dataset. Names added after 1997 are absent.
- (decision) On-this-day language follows the paper language setting, via the Wikipedia REST feed onthisday/selected. If that language is unsupported or the day is empty, use English and record the fallback.
- (decision) Currency rates come from the MNB daily exchange-rate service, GetCurrentExchangeRates, for EUR, USD, and CHF quoted as HUF per 1 unit. Print value, rate date, and source MNB. Weekends and holidays show the last published date.
- (decision) A fresh install's feed list, stored as settings rows, starts with Telex https://telex.hu/rss as local and Wired https://www.wired.com/feed/rss as interest. Fetch code reads settings and does not embed those URLs.
- (decision) Default weekend greeting is exactly: Yippie, weekend! You earned it! It stays editable.
- (decision) Each planner note is at most 120 characters, about three lines in a span-2 column. A longer note is rejected. The user asked for a recommendation and this number was adopted.
- (decision) Held-edition information alert fires after 1 hour. A feed counts as dead after 6 minutes of failure, so a failed feed is retried about once a minute. Other sources keep an hourly light check.
- (decision) Disk low, a warning that counts as degraded, is under 500 MB free. Disk critical, which makes /status down, is under 100 MB free. Adopted as the recommendation the user requested.
- (decision) Model-limit alert fires when today's requests reach 20, or 80 percent of the configured daily limit, whichever comes first. A normal edition is about 2 calls, and the cap is 1000, so 20 catches a runaway long before 800.
- (decision) Clock grace period is 1 hour. If NTP has not synced by then, /status is down.
- (decision) Duplex defaults on. The operator can turn it off. The question was the default, and the user confirmed duplex.
- (decision) Open questions from the first distill are closed. The exact Brother model number remains a milestone-0 observation, not an open product question.
