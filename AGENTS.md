## Commits

- Title on the first line: short, specific, and action-oriented.
- Leave the next line blank.
- Follow it with bullets that state what changed in this step.
- One commit per meaningful step.
- Keep unrelated changes in their own commits.
- Leave out an author line, a Co-authored-by trailer, and an agent tag.

<!-- /bmad:context -->

## Writing

When writing text a person reads, follow the humanizer skill. That includes documentation, website copy, comments, and other prose.

Leave source, schemas, and configuration files unchanged. When a comment sits in a code file, edit the comment wording only. Leave commit messages unchanged.
